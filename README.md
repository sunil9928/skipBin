# 🚛 SkipBin

> A modern React + Vite skip-bin hire website with an interactive booking flow, waste information, skip-bin selection, Adelaide location support, and a polished responsive UI.

## 🌐 Live Website

### **https://sunil9928.github.io/skipBin/**

---

## ✨ Highlights

- 🎨 Modern, responsive website UI
- 🌀 Smooth animations and 3D-style visual effects
- 🗑️ Skip-bin size showcase with interactive slider
- 📋 Seven-step booking experience
- ♻️ Waste-type information and accepted/not-accepted waste guidance
- 📍 Adelaide delivery location section
- 🗺️ Adelaide Google Maps link
- ❓ Interactive FAQ section
- 📰 Blog section
- 📱 Mobile-friendly responsive layouts
- ⚡ Built with React and Vite
- 🧭 React Router navigation

---

## 🧾 Booking Flow

The booking experience is organized into seven steps:

| Step | Details |
|---|---|
| **1** | Select Postcode |
| **2** | Select Waste Type |
| **3** | Select Skip Bin |
| **4** | Special Waste |
| **5** | Bin Delivery |
| **6** | Select Delivery Date |
| **7** | Select Payment Mode |

---

## 🗑️ Skip Bin Sizes

The website showcases:

**3 m³ · 4 m³ · 6 m³ · 9 m³ · 12 m³**

Each option includes an image, description, and booking action.

---

## ♻️ Waste Information

The site includes dedicated waste content covering categories such as:

- Construction waste
- General waste
- Green waste
- Mixed waste

It also provides accepted and not-accepted waste guidance within the waste information section.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/sunil9928/skipBin.git
cd skipBin
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local Vite URL shown in the terminal.

### Production build

```bash
npm run build
```

### Lint

```bash
npm run lint
```

### Preview the production build

```bash
npm run preview
```
